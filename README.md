🚀 Blinkit Clone MERN Project

A full-stack quick commerce web application inspired by Blinkit, built using the MERN Stack with real-time order tracking, multiple dashboards, inventory management, and delivery workflow automation.

🛒 Project Overview

The Blinkit Clone MERN Project is a complete quick-commerce platform designed to simulate real-world grocery delivery applications like Blinkit and Zepto.

This project includes:

✅ Customer Ordering System
✅ Admin Management Panel
✅ Picker Dashboard
✅ Delivery Partner Dashboard
✅ Real-Time Order Tracking
✅ COD & Online Payment Flow
✅ Inventory Management
✅ Google Maps Tracking
✅ Socket.IO Live Updates

The application is fully responsive and deployed using modern cloud platforms.

⚙️ How To Run Locally
1️⃣ Clone Repository
git clone https://github.com/YOUR_USERNAME/Grocery-Store-Project.git
2️⃣ Backend Setup
cd backend
npm install

Create .env

PORT=5000

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET

RAZORPAY_KEY_ID=YOUR_KEY

RAZORPAY_KEY_SECRET=YOUR_SECRET

Run Backend:

npm run dev
3️⃣ Frontend Setup
Customer Panel
cd frontend-customer
npm install
npm start
Admin Panel
cd frontend-admin
npm install
npm start
Picker Panel
cd frontend-picker
npm install
npm start
Delivery Panel
cd frontend-delivery
npm install
npm start
