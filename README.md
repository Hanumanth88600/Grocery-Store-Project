# Blinkit Clone MERN Project

A full-stack quick commerce application inspired by Blinkit.

## Features

- Customer Panel
- Admin Panel
- Picker Dashboard
- Delivery Dashboard
- Live Order Tracking
- COD + Online Payment
- Real-Time Socket.IO Updates
- Inventory Management
- Order Assignment System

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Axios
- Framer Motion

Backend:
- Node.js
- Express.js
- MongoDB
- Socket.IO

Database:
- MongoDB Atlas
